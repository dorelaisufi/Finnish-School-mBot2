# Finnish School mBot2

## What is mBot2?

mBot2 is an **educational robot** that we use in ICT lessons to learn programming and robotics. We can control it using *Python* and mBlock.

## What Can mBot2 Do?

mBot2 can:
- Move forward and backward.
- Detect obstacles using sensors.
- Follow lines on the floor.
- Display text on its screen.
- Change its RGB LED colours.

## What is CyberPi?

CyberPi is a small programmable computer that controls mBot2. It has a screen, buttons, sensors and a microphone.

## Three Important Features

1. Sensors help mBot2 detect objects.
2. CyberPi can display information.
3. RGB LEDs can show different colours.

## Why We Use mBot2 in ICT

We use mBot2 because it helps us understand **coding and robotics** in a practical way. We can write programs and see how the robot follows our instructions.
